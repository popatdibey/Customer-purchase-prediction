About this project

A machine learning application that predicts whether a customer will purchase, explains the prediction and groups customers into segments.

How it works

  1. Data collection A customer dataset (CSV) with demographics, browsing behaviour and purchase history.
  2. Preprocessing Missing values are imputed, categories are one-hot encoded and numbers are scaled, all inside one scikit-learn pipeline.
  3. Exploratory analysis Purchase rates by age, income, browsing time and visits, shown on the Dashboard.
  4. Model training Logistic Regression, Decision Tree and Random Forest, tuned with grid search and 5-fold cross-validation.
  5. Evaluation Accuracy, precision, recall, F1, ROC-AUC and confusion matrices on a held-out 20% test set.
  6. Deployment The best model is saved with Joblib and served through Flask.

Modules

Single prediction

Probability, segment and recommended action for one customer.

Explainable AI

A model-agnostic explanation shows which features pushed the probability up or down.

Customer segmentation

K-Means clustering groups customers into four behavioural segments.

Batch scoring

Upload a CSV, score every customer and download the results.

Analytics dashboard

Purchase patterns and segment profiles drawn with Chart.js.

Prediction history

Every prediction is logged in SQLite and can be exported.

REST API

POST /api/predict with JSON returns the prediction, factors and advice.

Model comparison

Side-by-side metrics, ROC curves, confusion matrices and feature importance.

Technology

Python, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Flask, SQLite, Chart.js, HTML and CSS.

Limitations and future scope

Predictions are only as good as the training data, so the model should be retrained on fresh customer records regularly. Future work could add live retraining from uploaded data, more features such as product category and device, and A/B testing of the recommended actions.
